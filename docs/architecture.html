The turns endpoint is the most complex. It calls Claude (or mock), saves the turn to DB, updates session score, awards badges, then returns just what the frontend needs. All raw analytics are stored in analyticsJson as a JSON string in SQLite.
🤖
Claude API Response Contract

This is the exact JSON structure we expect back from the Claude proxy (or mock). The partner team is responsible for generating this format.

Full Response Shape
{
  "character_reply": "string",
  "mission_complete": boolean,
  "teacher_analytics": {
    "grammar_points_observed": string[],
    "grammar_errors_frequent": string[],
    "target_vocabulary_used": string[],
    "missed_opportunities": string[],
    "confidence_score": number (0.0–1.0),
    "word_count": number,
    "struggle_detected": boolean,
    "teacher_brief": "string"
  },
  "gamification": {
    "points_earned": number,
    "character_mood": "😊",
    "achievements": string[]
  }
}
How Each Field Is Used
character_reply — Displayed as the character's chat bubble
mission_complete — When true, hides text input, shows "See Results" button
confidence_score — Averaged across all turns → shown on results screen
grammar_errors_frequent — Aggregated across sessions → teacher bar chart
points_earned — Added to session score in DB + SessionContext.score
character_mood — Emoji shown in conversation header, animates on change
achievements — Each badge saved to SessionBadge table + shown on results
teacher_brief — Last turn's brief shown on results + student detail page

Environment Variables
Variable Used In Purpose
MOCK_AI turns/route.ts, stt/route.ts, tts/route.ts true = bypass all external APIs, use fake responses. Essential for frontend dev.
DATABASE_URL lib/db/index.ts, prisma.config.ts Path to SQLite file. Default: file:./dev.db. Change for production (e.g. Turso libsql URL).
CLAUDE_PROXY_URL sessions/[id]/turns/route.ts Partner team's endpoint that wraps Claude. We POST student message + session context here.
CLAUDE_API_KEY sessions/[id]/turns/route.ts Sent as Authorization: Bearer header to Claude proxy.
WHISPER_API_URL api/stt/route.ts Whisper speech-to-text endpoint URL.
WHISPER_API_KEY api/stt/route.ts Auth key for Whisper endpoint.
ELEVENLABS_API_KEY api/tts/route.ts Auth for ElevenLabs. Sent as xi-api-key header.
ELEVENLABS_DEFAULT_VOICE api/tts/route.ts Default voice ID. Each scenario has a voiceEnvKey field you can use per-character.
⚠️ Variables starting with NEXT_PUBLIC_ are exposed to the browser. All keys above intentionally do not have that prefix — they stay server-side only.
